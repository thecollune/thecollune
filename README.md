# Collune

Collune is a collaboration platform that helps brands discover, evaluate, and work with creators. It brings creator discovery, campaign management, messaging, and campaign delivery into one workflow, with an internal admin console for operational oversight.

> This repository contains product code for Collune. It is public for transparency and portfolio purposes; it is not currently presented as an open-source contribution project or a hosted service SLA.

## The problem

Influencer and creator partnerships are often managed through spreadsheets, DMs, and disconnected social-platform data. That makes it difficult for brands to find relevant creators, compare options, manage applications and deliverables, and keep communication in one place. Creators, meanwhile, need a clear way to present their portfolio, rates, social accounts, and campaign work.

Collune addresses this by providing:

- **Creator discovery:** searchable creator profiles, portfolios, social accounts, rate cards, and shortlists.
- **Campaign collaboration:** campaign publishing, applications, review, work submissions, and delivery status.
- **A shared communication layer:** real-time chat, notifications, and unread-message reminders.
- **Operational control:** verification, role-based administration, reporting, and configurable rate-card options.
